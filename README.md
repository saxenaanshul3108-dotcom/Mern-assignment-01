# MERN Assignment 01

Weekly web development assignments (Week 2 to Week 9), covering HTML and CSS from the basics to a responsive landing page.

**Author:** Anshul
**GitHub:** [saxenaanshul3108-dotcom](https://github.com/saxenaanshul3108-dotcom)

---

## Projects

| Week | Project | Topics Covered |
|------|---------|----------------|
| 02 | My Resume Page | HTML basics, headings, paragraphs, bold and italic, `div` with `id` and `class`, comments |
| 03 | My Portfolio Page | Links, images, nested lists, semantic tags (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`) |
| 04 | Club Event and Registration Page | Tables, forms, labels, inputs, radio buttons, checkboxes, dropdown, textarea, meta tags, favicon |
| 05 | Style the Club Page | CSS fundamentals, selectors, fonts, colours, `:root` variables with `var()` |
| 06 | Profile Card | Box model, `border-box`, circle avatar, scrolling box with `overflow`, `sticky` and `fixed` positioning, `z-index` |
| 07 | Landing Page Header | Flexbox navbar, centred banner, wrapping cards with `flex: 1 1 200px` |
| 08 | Dashboard | CSS Grid, `grid-template-areas`, `repeat(auto-fit, minmax())`, Flexbox inside grid items |
| 09 | Responsive Landing Page (TravelEase) | Mobile-first design, media queries at 768px and 1024px, `rem` units, responsive images |

## How to Run

No installation is needed. These are plain HTML and CSS projects.

1. Clone the repository:
   ```bash
   git clone https://github.com/saxenaanshul3108-dotcom/Mern-assignment-01.git
   ```
2. Open any week's folder.
3. Double-click the `index.html` file (or `resume.html` in Week 02) to open it in your browser.

Tip: for the best experience in VS Code, use the **Live Server** extension to see changes instantly.
